4. NO ERRORS FROM THE MODESET / IGT TIERS
======================================================================
  - Every modetest -s run produced exactly the two expected informational lines
    (SiI9024A not-ready + backbuffer staging) and nothing else.
  - No IGT run produced any kernel message: kms_addfb_basic (including the size-max
    FAIL) added 0 dmesg lines, so that FAIL is ioctl-level only.
  - kmscube with stdin held produced 2 lines and no error.
  - The only recurring non-error oddity is the SiI9024A message, emitted on every mode
    program:
      SiI9024A receiver not ready after 2000 ms: HPD=1 RSEN=0 status=04; enabling for
      compatibility
    Source: src/sii902x.c:578, in
      static int sii902x_wait_receiver_ready(struct device *dev, unsigned char *status)
    which loops for 2000 ms waiting for RSEN to be stable for 100 ms. RSEN=0 means the
    TMDS receiver reports no sense, yet the driver enables the output anyway "for
    compatibility". This costs 2 s per mode program and means the driver cannot confirm
    the panel's receiver is actually ready. Recorded as a finding, not an error.
