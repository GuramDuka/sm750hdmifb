Line 1245 is the defect. It is emitted by the DRM core, not by this driver:
drm_mode_config_validate() runs at drm_dev_register() and calls
validate_blend_mode_for_alpha_formats() for every plane. That function returns
immediately when plane->blend_mode_property is set and otherwise walks the
plane's format list, warning for the first format whose drm_format_info has
has_alpha. The cursor plane advertises DRM_FORMAT_ARGB8888 and had no blend
property, so the check fired.
