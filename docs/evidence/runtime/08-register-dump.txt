WHY THIS FILE EXISTS
---------------------
GAP-B4 was open because the loaded 0.5.9 module exposed no debugfs regs file, so
sm750-regs failed with 'sm750-regs: /sys/kernel/debug/dri/0/regs not readable'.
After T11 loaded 0.6.0 the same command returns a 49-register dump. This file
records the command working and a before/after pair across one modeset.

NOTE ON HOW THE MODESET HAD TO BE CAPTURED
------------------------------------------
modetest -s applies the mode and then keeps its DRM fd open until it is killed;
when the LAST fd closes, drm_lastclose runs the driver's fbdev client restore and
the panel returns to the preferred 1920x1080 mode. Dumping after 'modetest -s ...;'
therefore shows the restored mode, not the mode that was set. The pair below is
taken with the setting client still alive, which is the only way to see the 1024x768
register state. A third dump after the client exits proves the restore is complete.

=== INTERPRETATION OF THE THREE RESIDUAL DIFFERENCES ===
  PANEL_CURRENT_LINE (0x080034) is the live scanline counter; it differs on every
    read and carries no state. Ignore it for comparison purposes.
  PANEL_FB_ADDRESS (0x08000c) 0x00000000 -> 0x003f4800 is the fbdev client
    re-allocating its framebuffer object; the offset moves, the mode does not.
  MISC_CTRL (0x000004) 0x01020060 -> 0x01000060 clears bit 17 (0x00020000).
    src/ddk750_reg.h defines no name for MISC_CTRL bit 17; the register table in
    docs/REGISTERS.md:52 lists MISC_CTRL without that bit. Recorded as an
    observation, not a defect: bit 17 is not written by any code path in src/.

=== CONTROL EXPERIMENT: is a modeset actually reaching the panel registers? ===
  Eight consecutive modetest -s 35@38:1024x768-60 runs were raced against 633
  back-to-back register dumps. Both register states were observed, which proves
  the 1024x768 programming is real and the single-dump result is a sampling race,
  not a modeset that failed to apply:
    PANEL_HORIZONTAL_TOTAL  0x053f03ff (1024 wide) seen 314x / 0x0898077f (1920 wide) seen 319x
    PANEL_VERTICAL_TOTAL    0x032502ff (768 high)  seen 314x / 0x04640437 (1080 high) seen 319x
    PANEL_FB_WIDTH          0x08000800 (1024)     seen 314x / 0x0f000f00 (1920)     seen 319x
