1. The driver contract
----------------------
src/sm750_drm.c:4933-4949, active_crtc_show():

    int index = -1;
    ...
    if (READ_ONCE(crtc->enabled))
        index = drm_crtc_index(crtc);

branch to `if (0)`, so the copy parses -1 through parse_u64() again and must
