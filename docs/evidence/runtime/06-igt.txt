  (kms_setmode:879888) igt_kms-CRITICAL: Last errno: 13, Permission denied
  Stack: #1 [kmstest_set_vt_graphics_mode+0x66]
  (identical text from kms_atomic, kms_flip, kms_pipe_crc_basic, kms_rmfb)

  BLOCKING DEPENDENCY CHAIN, verbatim and complete:
    1. IGT test calls kmstest_set_vt_graphics_mode() as part of its standard test loop.
    2. That function opens /dev/tty0 to issue KDSETMODE / VT_ACTIVATE.
    3. /dev/tty0 is crw------- root tty; coder (uid 1005) is not root and is not in a
       group with access, so open() / the ioctl returns EACCES.
    4. igt_kms asserts ret >= 0 and aborts the subtest with errno 13.
  Consequence: on this host, unprivileged, no IGT test that switches VT graphics mode
  can reach the driver. That covers kms_setmode, kms_atomic, kms_flip,
  kms_pipe_crc_basic and kms_rmfb.
  The fix would require either running IGT as root or an ACL on /dev/tty0 - both
  outside this task's constraints (no root, no sudo beyond the allowlist).
