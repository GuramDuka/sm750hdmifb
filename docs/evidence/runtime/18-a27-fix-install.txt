5. PROOF THAT THE FIXED CODE IS THE LOADED CODE
------------------------------------------------
$ cat /sys/module/sm750hdmidrm/version      -> 0.6.0
$ cat /sys/module/sm750hdmidrm/srcversion   -> 07E8F503FC7D839EEC5EE64
$ modinfo -F srcversion sm750hdmidrm        -> 07E8F503FC7D839EEC5EE64
The srcversion changed from F4E135E09C9898462FE24C5 to 07E8F503FC7D839EEC5EE64,
so the object the kernel loaded is not the object it had before.

$ xz -dc /lib/modules/7.3.4-100.fc43.x86_64/extra/sm750hdmidrm.ko.xz > installed.ko
$ sha256sum installed.ko

$ modinfo -F srcversion installed.ko        -> 07E8F503FC7D839EEC5EE64
$ strings installed.ko | grep -c 'commit finished, event consumed'
1
$ strings installed.ko | grep -c 'failed to enable HDMI mode'
1
The literal "commit finished, event consumed" exists only in the fixed source
(src/sm750_drm.c:3118), so an installed object that contains it cannot be the
pre-fix build. The reproduction evidence (19-a27-fix-reproduce.txt) shows the
same string being printed at run time, which is the stronger statement: the
kernel is executing the new fail path.

6. TWO NOTES ON THE INSTALL OUTPUT
-----------------------------------
- dkms printed "warning: skipping 6.18.13-200.fc43.x86_64: matching kernel
  headers are absent". There is no installed kernel 6.18.13-200 on this host:
  `rpm -qa | grep ^kernel` lists 7.2.15-100, 7.3.3-100 and 7.3.4-100 only, and
  /lib/modules/6.18.13-200.fc43.x86_64 is a stale directory left by the NVIDIA
  driver that belongs to no package (docs/ENVIRONMENT.md:79-84). The build
  matrix is therefore complete for every installed kernel: dkms built and
  installed 0.6.0 for all three (section 3).
- The "Deprecated feature: CLEAN" lines come from dkms.conf's CLEAN setting and
  predate this task; they are not errors and the exit codes are 0.

7. PANEL STATE ACROSS THE RELOAD
---------------------------------
Immediately after `modprobe sm750hdmidrm` the connector reads
connected / disabled / On: the driver's own fbdev client re-registers the CRTC
and the output comes back on the first modeset. The reproduction harness
restores 1920x1080 before it records anything, and its first attempt already
reads connected / enabled / On; the final state after 108 attempts is the same
(section 6 of 19-a27-fix-reproduce.txt). The desktop is not affected at any
point: Plasma runs on the GTX 1070 (card1), while card0 drives the SM750 HDMI
console only.
