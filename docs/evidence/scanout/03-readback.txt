What the dump prints when it can be read
----------------------------------------
src/sm750_drm.c: sm750_scanout_show() emits a summary and a hex dump of the
same bounded region the CRC source hashes:

    # sm750hdmidrm scanout readback, 1920x1080 pitch 3840
    offset 0
    length 262144
    nonzero <count>
    crc32 0x<8 hex digits>
    00000000: xx xx xx xx xx xx xx xx xx xx xx xx xx xx xx xx
    ...

offset is the visible scanout offset in VRAM, length is crc_window_bytes
rounded down to a multiple of 4 and clamped to the visible area (scanout_pitch
* vdisplay), nonzero is the number of nonzero bytes in that span and crc32 is
the low 32 bits of the zlib-compatible crc32 of the same span.

No numbers are quoted here: none were measured. Closing action is one root run
of `make crc-check`, which writes the PASS/FAIL lines to
docs/evidence/scanout/04-checks.txt and a trimmed dump excerpt to this file.
