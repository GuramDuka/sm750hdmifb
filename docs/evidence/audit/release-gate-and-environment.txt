Observed:

  3
  $ ./tests/audit-release.sh
  exit=1
  Restrictive licence marker found in releasable code.

Cause:
  build-package.sh:79-90 archives the working tree ("src docs tests tools packaging .github")
  with exclude patterns only for VCS metadata and build artifacts. Any untracked file under
  those directories (here docs/plan/20261117-sm750-driver-prod/plan.yaml) is shipped in the
  source tarball and is then scanned by tests/audit-release.sh:33-59, which greps the shipped
  text for restrictive licence markers and private paths.

Impact:
  A clean checkout passes the release audit; a working tree containing local planning or
  audit notes fails with exit 1, and would ship those notes if the marker check were absent.
